# unsubscribird-forge

Model work for the un-subscribird bird station: exporting, compiling, training and evaluating the models it runs,
starting with bird detection and BioCLIP 2 species embeddings on the Orange Pi 6's NPU.

The board's kernel, NPU driver and library come from [jbuck2005/orangepi6](https://github.com/jbuck2005/orangepi6).
The station software itself lives in un-subscribird and carries no NPU code.
